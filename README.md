# Creactiva

Proyecto personal de desarrollo web creado como parte de mi aprendizaje en programación y desarrollo de aplicaciones web.

## Descripción

Creactiva es una página web que he desarrollado para poner en práctica mis conocimientos, mejorar mis habilidades técnicas y construir mi portfolio de proyectos.

## Tecnologías utilizadas

- HTML5 — estructura y contenido.
- CSS3 — estilos y diseño visual.
- JavaScript — interactividad y funcionalidades.
- GitHub — alojamiento y control de versiones del código.
- Netlify — publicación de la página web.

## Ver el proyecto

[Visitar Creactiva](https://creactivamd.netlify.app/)

## Objetivos de aprendizaje

- Aplicar los fundamentos del desarrollo web.
- Organizar los archivos de un proyecto.
- Trabajar con HTML, CSS y JavaScript.
- Publicar y documentar un proyecto en GitHub.
- Mejorar progresivamente la calidad del código.

## Estado del proyecto

Proyecto personal en evolución, sujeto a mejoras y nuevas funcionalidades.
